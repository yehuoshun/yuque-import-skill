## 本次新踩的坑（已并入 references 坑 54）

1. ⚠️ **CSDN 反爬 = HTTP 521**：连续/快速请求会回 521 + 2KB 空壳。本库 130 页在首轮探测里就中了 2 页，
   **退避重试（3/6/9…S）后全部 200**。判据别只看状态码——**响应里没有 `content_views` 就当失败重试**。
2. **正文容器 = `div#content_views`**（干净，广告/推荐位在容器外，天然不沾）；
   文章自身标题 = `h1.title-article`（在容器外；`<title>` 带「_CSDN博客」后缀要剥）。
3. **代码块 `<pre><code class="language-java">`** —— 语言直接从 code 的 class 取（本库 225 个代码块**全带语言**）。
4. ⚠️ **CSDN 的 `<table>` 是版式盒子不是数据表**：`<table border="1">` 常被做成「思考」提示框
   （外层 1 行 1 格、内嵌 1 张表）→ 按数据表渲会出一堆空单元格/图标格。判据：**含嵌套 table 或每行 ≤1 格 →
   渲成 `> ` 引用块**（本库 248 处引用块）。
5. **图片**：2012-2014 的老图域名还活着（`img-my.csdn.net`、`img-blog.csdn.net`，带
   `Referer: https://blog.csdn.net/` 全 200）；但**表情图 `static.blog.csdn.net/xheditor/xheditor_emot/default/*.gif` 已 404** → 跳过；
   无扩展名 URL（如 `.../20131223220903125`）要靠 `Content-Type` 猜扩展名存盘。
6. **索引页的站内链接渲成纯文本**（SOP 一致）——索引 doc 里留下的是「标题 + 一句说明」的清单，可读。
