## zDoc 语法（doc/manual/zdoc/syntax.man 官方规范）
| 语法 | 含义 | 转换 |
|---|---|---|
| `#title: xxx` / `#index:` / `#author:` | 头部元数据 | 剥 |
| `----`（≥5 个 `-`） | 分隔线 | `---` |
| 缩进（Tab） | 父子层级；**拥有子的行 = 标题行** | 深度 0 有子 → `##`；深度 n → `#`×(n+2) |
| `* item` / `# item` | 无序/有序列表 | `-` / `1.` |
| `[url text]` | 超链接 | `[text](url)`；**站内 `.man` 链接（含 `#锚点`）→ 转纯文本（死链）** |
| `` `code` `` | 行内代码 | 保留 |
| `{*b}` `{/i}` `{_u}` `{~s}` `{#F00;x}` | 粗/斜/下划线/删除线/彩色 | `**`/`*`/`<u>`/`~~`/剥色留样式 |
| `<img>` `<WxH:img>` | 图片 | `![name](path)`（保留相对路径，rewrite 传 CDN） |
| `{{{<lang>` ... `}}}` | 代码块 | ` ```lang ` 围栏（lang 归一化映射：JAVA→java 等） |
| `||a||b||` | 表格行（连续 = 表格） | `\| a \| b \|` + 分隔行 |
| 行尾 `\` | 续行符 | 与下一行拼接 |

## 踩过的坑
1. **缩进层级 = tab 数 + 空格数//4**，不是字符数——`\t 文本`（tab+空格）混排若按 `len-lstrip` 算会误判深一层
2. **代码块 depth 按 `{{{` 行的实际缩进**，不是固定 0（否则代码块脱离父标题）
3. **style 正则分组错位**：`{(#hex;)?([*/_~]+)(内容)}`——颜色、样式字母、内容三段；`{cid}` 这类 JSON/占位符（无样式字母）**原样保留花括号**
4. **img 正则与链接正则打架**：img 输出 `![x](y)` 会被 `\[([^\]]+)\]` 链接正则二次处理 → 链接正则加 `(?<!!)` 负向断言
5. **语法教学文档**（如 zDoc syntax.man）里的图全是示例 → 转行内代码 `` `<../logo.png>` `` 保留原文（路径本地不存在即示例）
6. 链接文字内嵌图片的混合形态（`[url <img>]`）极少见（1 处）→ 手动修
