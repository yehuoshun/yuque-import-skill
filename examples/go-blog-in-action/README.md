# 《Go语言博客实践》(Go Blog In Action)（fpb52 #109）

- 仓库 `achun/Go-Blog-In-Action` @ `d8e2120`（drinker / Martini 版；master 是老版本）。
- 形态：**8 个 `ChapterNN.md`**，一章一篇，无子目录、无图。→ 9 节点扁平（00-说明 + 01~08），零填充前缀字典序即书序，**免归位**。
- 口径：一个文件 = 一章 = 一页（GitHub 上本书也是章页 + 章内锚点，**不硬拆节**）；章标题取仓库 README 目录（源文件 H1 是节名）。
- 三个转换要点：
  1. **setext/ATX 混排**：有的章节标题是 `标题\n====`，有的是 `## 标题`，第 7 章是 ATX `#` → 统一「一级标题降为 `##`，其余依次降一级」，**必须跟代码围栏**。
  2. **引用式链接要内联**：`[文字][1]`、`[文字][]` + 文末 `[1]: url "title"` 定义块 → 内联后删定义。⚠️ 定义行常带 `"标题"`，正则必须是 `\[x\]:\s*(\S+)(\s+["'(].*)?$`，只认 `[x]: url` 会漏 20 处。
  3. README 的目录清单（`第N章/第N节` + `ChapterNN.md#锚点`）与语雀 TOC 重复且是死链 → 剔；README 里的 `--------` 分隔线要先删（它也是 setext 下划线）。
- 产出：9 节点、无图，六查全绿；库 **85155099**（slug `go-blog-in-action-d8e2120`）。CJK 损耗 18（定义块里的链接 title 文本）。
